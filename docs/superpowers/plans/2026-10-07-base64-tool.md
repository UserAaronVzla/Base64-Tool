# Base64 Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an offline, single-file HTML recreation of base64decode.org (text and file encode/decode, site options, PEM handling, hex view) whose core logic is unit-tested.

**Architecture:** Pure conversion logic lives in `src/core.js` (UMD: browser global `B64`, Node `module.exports`) and is tested with `node --test`. `src/ui.js` only wires the DOM to `B64`. `build.mjs` inlines `style.css`, `core.js` and `ui.js` into the `src/index.html` template, producing `dist/base64-tool.html`, the only file the user opens.

**Tech Stack:** Vanilla JS (ES2020), HTML, CSS. Node v24 built-ins only (`node:test`, `node:assert`, `node:fs`, `node:child_process`). No npm packages, no `package.json`.

**Spec:** `docs/superpowers/specs/2026-10-07-base64-tool-design.md`

## Global Constraints

- No runtime dependencies, no CDN, fonts or external assets; the built file contains no `http(s)://` in `src=`, `href=` or `url(...)`.
- Built HTML carries exactly: `<meta http-equiv="Content-Security-Policy" content="default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:">`
- Build and test use only Node built-ins; commands are `node build.mjs` and `node --test` from the project root.
- Encode charsets: `utf-8`, `utf-16le`, `utf-16be`, `iso-8859-1`. Decode charsets: the WHATWG `TextDecoder` list in `DECODE_CHARSETS`.
- Base64 is hand-rolled over `Uint8Array`; never use `btoa`/`atob`.
- MIME split = CRLF every 76 chars. PEM = 64-char lines, `-----BEGIN <label>-----` / `-----END <label>-----`, default label `CERTIFICATE`.
- Live-mode debounce ~150 ms; live mode auto-disables above 10 MB input; hex dump capped at 64 KB (65536 bytes).
- **Deliberate UI deviation from spec, recorded here:** the Decode tab shows a hint ("Standard and URL-safe alphabets are both accepted") instead of a URL-safe checkbox, because the spec makes `urlSafe` a no-op for decoding and a checkbox that does nothing would mislead.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- All paths below are relative to the project root `Base64-Tool/` (git repo already initialized; spec already committed).

## Review Focus

1. **Error positions must point at what the user actually pasted**, including leading whitespace, newlines and PEM preamble text. Pinned in Task 1 ("invalid character reports position in the original input") and Task 3 ("error position inside a PEM body refers to the original input").
2. **Windows CRLF input in per-line mode.** Lines must not carry a stray `\r`, and blank lines must be preserved so output lines align with input lines. Pinned in Task 2 (two per-line tests).
3. **Large inputs.** A 5 MB buffer must encode/decode without stack overflow or a multi-second hang (Task 1 test). Above 10 MB, live mode must switch itself off (Task 6 browser check). Encoded output over 5 MB must not be dumped into a textarea (Task 7 browser check).
4. **PEM produced by real tools.** Expect `openssl pkcs12` output with "Bag Attributes" preamble, CRLF line endings, multi-word labels (`RSA PRIVATE KEY`) and trailing junk. Pinned in Task 3.
5. **Dropping a file outside the drop zone.** The browser must not navigate away and wipe the user's work. Pinned in Task 7 (window-level `dragover`/`drop` handlers plus browser check).

```js
/* Base64 Tool core: pure functions, no DOM. Browser global `B64`, Node `module.exports`. */
(function (root, factory) {
  const api = factory();
  if (typeof module === 'object' && module.exports) module.exports = api;
  else root.B64 = api;
})(typeof self !== 'undefined' ? self : this, function () {
  'use strict';

  const STD_ALPHABET = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/';
  const URL_ALPHABET = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_';

  // Char code -> sextet value; accepts both alphabets. -1 = invalid.
  const LOOKUP = new Int16Array(128).fill(-1);
  for (let i = 0; i < 64; i++) {
    LOOKUP[STD_ALPHABET.charCodeAt(i)] = i;
    LOOKUP[URL_ALPHABET.charCodeAt(i)] = i;
  }

  class Base64Error extends Error {
    constructor(message, position = null, char = null) {
      super(message);
      this.name = 'Base64Error';
      this.position = position;
      this.char = char;
    }
  }

  function splitLines(s, width, sep) {
    if (s.length <= width) return s;
    const parts = [];
    for (let i = 0; i < s.length; i += width) parts.push(s.slice(i, i + width));
    return parts.join(sep);
  }

  function encodeBytes(bytes, opts = {}) {
    const alphabet = opts.urlSafe ? URL_ALPHABET : STD_ALPHABET;
    const len = bytes.length;
    let s = '';
    let i = 0;
    for (; i + 2 < len; i += 3) {
      const n = (bytes[i] << 16) | (bytes[i + 1] << 8) | bytes[i + 2];
      s += alphabet[(n >> 18) & 63] + alphabet[(n >> 12) & 63] + alphabet[(n >> 6) & 63] + alphabet[n & 63];
    }
    const rem = len - i;
    if (rem === 1) {
      const n = bytes[i] << 16;
      s += alphabet[(n >> 18) & 63] + alphabet[(n >> 12) & 63] + (opts.urlSafe ? '' : '==');
    } else if (rem === 2) {
      const n = (bytes[i] << 16) | (bytes[i + 1] << 8);
      s += alphabet[(n >> 18) & 63] + alphabet[(n >> 12) & 63] + alphabet[(n >> 6) & 63] + (opts.urlSafe ? '' : '=');
    }
    return opts.mimeSplit ? splitLines(s, 76, '\r\n') : s;
  }

  function charAt(text, i) {
    return String.fromCodePoint(text.codePointAt(i));
  }

  // Decode `text`; `offset` is added to reported positions so they refer to the caller's original input.
  function decodeClean(text, offset) {
    const vals = new Uint8Array(text.length);
    let count = 0;
    let padSeen = false;
    for (let i = 0; i < text.length; i++) {
      const c = text.charCodeAt(i);
      if (c === 32 || c === 9 || c === 10 || c === 13 || c === 11 || c === 12) continue;
      if (c === 61) { padSeen = true; continue; }
      if (padSeen) {
        throw new Base64Error(`Unexpected data after padding at position ${i + offset}`, i + offset, charAt(text, i));
      }
      const v = c < 128 ? LOOKUP[c] : -1;
      if (v < 0) {
        const ch = charAt(text, i);
        throw new Base64Error(`Invalid character '${ch}' at position ${i + offset}`, i + offset, ch);
      }
      vals[count++] = v;
    }
    const rem = count % 4;
    if (rem === 1) {
      throw new Base64Error(`Invalid Base64 length: ${count} characters (the last group has only one character)`);
    }
    const out = new Uint8Array(Math.floor(count / 4) * 3 + (rem === 0 ? 0 : rem - 1));
    let o = 0;
    let j = 0;
    for (; j + 3 < count; j += 4) {
      const n = (vals[j] << 18) | (vals[j + 1] << 12) | (vals[j + 2] << 6) | vals[j + 3];
      out[o++] = (n >> 16) & 255;
      out[o++] = (n >> 8) & 255;
      out[o++] = n & 255;
    }
    if (rem === 2) {
      const n = (vals[j] << 18) | (vals[j + 1] << 12);
      out[o++] = (n >> 16) & 255;
    } else if (rem === 3) {
      const n = (vals[j] << 18) | (vals[j + 1] << 12) | (vals[j + 2] << 6);
      out[o++] = (n >> 16) & 255;
      out[o++] = (n >> 8) & 255;
    }
    return out;
  }

  // `opts.urlSafe` is accepted for symmetry; decoding always accepts both alphabets.
  function decodeToBytes(input, opts = {}) {
    return decodeClean(String(input), 0);
  }

  return {
    Base64Error,
    encodeBytes, decodeToBytes,
  };
});
```

```js
  // ---- charsets

  const ENCODE_CHARSETS = ['utf-8', 'utf-16le', 'utf-16be', 'iso-8859-1'];
  const DECODE_CHARSETS = [
    'utf-8', 'utf-16le', 'utf-16be', 'windows-1252',
    'iso-8859-2', 'iso-8859-3', 'iso-8859-4', 'iso-8859-5', 'iso-8859-6', 'iso-8859-7', 'iso-8859-8',
    'iso-8859-10', 'iso-8859-13', 'iso-8859-14', 'iso-8859-15', 'iso-8859-16',
    'windows-1250', 'windows-1251', 'windows-1253', 'windows-1254', 'windows-1255', 'windows-1256',
    'windows-1257', 'windows-1258', 'windows-874', 'koi8-r', 'koi8-u', 'ibm866', 'macintosh',
    'shift_jis', 'euc-jp', 'iso-2022-jp', 'euc-kr', 'gbk', 'gb18030', 'big5',
  ];

  function makeDecoder(charset) {
    try {
      return new TextDecoder(charset);
    } catch (e) {
      throw new Error(`Unsupported charset: ${charset}`);
    }
  }

  function supportedDecodeCharsets() {
    return DECODE_CHARSETS.filter((cs) => {
      try { new TextDecoder(cs); return true; } catch (e) { return false; }
    });
  }

  function textToBytes(str, charset = 'utf-8') {
    const cs = String(charset).toLowerCase();
    if (cs === 'utf-8') return new TextEncoder().encode(str);
    if (cs === 'utf-16le' || cs === 'utf-16be') {
      const be = cs === 'utf-16be';
      const out = new Uint8Array(str.length * 2);
      for (let i = 0; i < str.length; i++) {
        const u = str.charCodeAt(i);
        out[2 * i] = be ? u >> 8 : u & 255;
        out[2 * i + 1] = be ? u & 255 : u >> 8;
      }
      return out;
    }
    if (cs === 'iso-8859-1') {
      const out = new Uint8Array(str.length);
      for (let i = 0; i < str.length; i++) {
        const u = str.charCodeAt(i);
        if (u > 255) {
          throw new Error(`Character '${charAt(str, i)}' at position ${i} cannot be encoded as ISO-8859-1`);
        }
        out[i] = u;
      }
      return out;
    }
    throw new Error(`Encoding to ${charset} is not supported (supported: ${ENCODE_CHARSETS.join(', ')})`);
  }

  function bytesToText(bytes, charset = 'utf-8') {
    return makeDecoder(charset).decode(bytes);
  }

  function splitInputLines(s) {
    return String(s).split(/\r?\n/);
  }

  function encodeText(str, opts = {}) {
    const charset = opts.charset || 'utf-8';
    if (opts.perLine) {
      return splitInputLines(str)
        .map((line) => encodeBytes(textToBytes(line, charset), { urlSafe: opts.urlSafe }))
        .join('\n');
    }
    return encodeBytes(textToBytes(str, charset), { urlSafe: opts.urlSafe, mimeSplit: opts.mimeSplit });
  }

  function decodeText(b64, opts = {}) {
    const decoder = makeDecoder(opts.charset || 'utf-8');
    if (opts.perLine) {
      return splitInputLines(b64)
        .map((line, idx) => {
          if (line.trim() === '') return '';
          try {
            return decoder.decode(decodeToBytes(line));
          } catch (e) {
            return `[line ${idx + 1}: ${e.message}]`;
          }
        })
        .join('\n');
    }
    return decoder.decode(decodeToBytes(b64));
  }
```

```js
  // ---- PEM

  const PEM_RE = /-----BEGIN ([^\r\n-][^\r\n]*?)-----([\s\S]*?)-----END \1-----/;

  function detectPem(text) {
    const m = PEM_RE.exec(String(text));
    if (!m) return null;
    return { label: m[1], body: m[2], start: m.index + '-----BEGIN '.length + m[1].length + '-----'.length };
  }

  function stripPem(text) {
    const pem = detectPem(text);
    return pem ? pem.body : text;
  }

  function wrapPem(b64, label = 'CERTIFICATE') {
    const body = String(b64).replace(/\s+/g, '');
    return `-----BEGIN ${label}-----\n${splitLines(body, 64, '\n')}\n-----END ${label}-----\n`;
  }
```

```js
  // ---- binary helpers

  function looksBinary(bytes, charset = 'utf-8') {
    const sample = bytes.subarray(0, 4096);
    if (sample.length === 0) return false;
    let text;
    try {
      text = new TextDecoder(charset).decode(sample);
    } catch (e) {
      return true;
    }
    let total = 0;
    let bad = 0;
    for (const ch of text) {
      const c = ch.codePointAt(0);
      if (c === 0) return true;
      total++;
      if ((c < 32 && c !== 9 && c !== 10 && c !== 13) || c === 127 || c === 0xfffd) bad++;
    }
    return bad / total > 0.1;
  }

  function hexDump(bytes, maxBytes = 65536) {
    const n = Math.min(bytes.length, maxBytes);
    const lines = [];
    for (let off = 0; off < n; off += 16) {
      const end = Math.min(off + 16, n);
      let hex = '';
      let ascii = '';
      for (let k = 0; k < 16; k++) {
        if (off + k < end) {
          const b = bytes[off + k];
          hex += b.toString(16).padStart(2, '0') + ' ';
          ascii += b >= 32 && b < 127 ? String.fromCharCode(b) : '.';
        } else {
          hex += '   ';
        }
        if (k === 7) hex += ' ';
      }
      lines.push(`${off.toString(16).padStart(8, '0')}  ${hex} |${ascii}|`);
    }
    return { text: lines.join('\n'), truncated: bytes.length > maxBytes };
  }
```

```js
import { readFileSync, writeFileSync, mkdirSync, existsSync } from 'node:fs';

const root = dirname(fileURLToPath(import.meta.url));
const srcDir = resolve(process.argv[2] || join(root, 'src'));
const outFile = resolve(process.argv[3] || join(root, 'dist', 'base64-tool.html'));

function fail(message) {
  console.error(`build failed: ${message}`);
  process.exit(1);

const template = readFileSync(join(srcDir, 'index.html'), 'utf8');
const html = template.replace(/<!--\s*inline:([\w.-]+)\s*-->/g, (_, name) => {
  const file = join(srcDir, name);

  }

});

mkdirSync(dirname(outFile), { recursive: true });
```

```js
      const opt = document.createElement('option');
      opt.value = cs;
      opt.textContent = cs.toUpperCase();
      select.appendChild(opt);
    }
  }

  function download(data, filename, type) {
    const url = URL.createObjectURL(new Blob([data], { type: type || 'application/octet-stream' }));
    const a = document.createElement('a');
    a.href = url;
    a.download = filename || 'download';
    document.body.appendChild(a);
    a.click();
    a.remove();
    setTimeout(() => URL.revokeObjectURL(url), 1000);
  }

  async function copyText(text, button) {
    try {
      await navigator.clipboard.writeText(text);
    } catch (e) {
      const ta = document.createElement('textarea');
      ta.value = text;
      document.body.appendChild(ta);
      ta.select();
      document.execCommand('copy');
      ta.remove();
    }
    const label = button.textContent;
    button.textContent = 'Copied';
    setTimeout(() => { button.textContent = label; }, 1200);
  }

  function debounce(fn, ms) {
    let timer;
    return () => {
      clearTimeout(timer);
      timer = setTimeout(fn, ms);
    };
  }

  function formatSize(n) {
    if (n < 1024) return `${n} B`;
    if (n < 1024 * 1024) return `${(n / 1024).toFixed(1)} KB`;
    return `${(n / (1024 * 1024)).toFixed(1)} MB`;
  }

  // Live mode: re-run on input (debounced) and on option changes; off automatically for huge input.
  function wireLive({ input, live, run, notes, options }) {
    const runLater = debounce(run, 150);
    input.addEventListener('input', () => {
      if (!live.checked) return;
      if (input.value.length > LARGE_INPUT) {
        live.checked = false;
        setMsg(notes, 'Live mode turned off: input is larger than 10 MB. Use the button instead.');
        return;
      }
      runLater();
    });
    for (const el of options) el.addEventListener('change', () => { if (live.checked) run(); });
    live.addEventListener('change', () => { if (live.checked) run(); });
    input.addEventListener('keydown', (e) => {
      if (e.key === 'Enter' && (e.ctrlKey || e.metaKey)) {
        e.preventDefault();
        run();
      }
    });
  }
```

```js
      }

      const bytes = B64.decodeToBytes(text);
      lastDecoded = bytes;
      const notes = [];
      if (pem) notes.push(`PEM: ${pem.label} detected, armor stripped`);
      notes.push(`${formatSize(bytes.length)} decoded`);

        dec.output.value = dump.text;
        notes.push('binary data, showing hex dump' + (dump.truncated ? ' (first 64 KB only; Download saves everything)' : ''));

      }

    } catch (e) {
```

```js
  const MAX_DISPLAY = 5 * 1024 * 1024;
  const file = {
    drop: $('drop'), pick: $('file-pick'), input: $('file-input'), info: $('file-info'),
    encOpts: $('file-enc-opts'), mime: $('file-mime'), pem: $('file-pem'), pemLabel: $('file-pemlabel'),

  let fileResult = null; // { data: string | Uint8Array, type: string }

  function fileMode() {
    return document.querySelector('input[name="file-mode"]:checked').value;
  }

  function resetFileResult() {
    fileResult = null;
    file.output.value = '';
    setMsg(file.error, '');
    setMsg(file.notes, '');
  }

  function suggestFilename() {
    if (!currentFile) return;
    const name = currentFile.name;
    if (fileMode() === 'encode') {
      file.filename.value = name + (file.pem.checked ? '.pem' : '.b64');
    } else {
      const base = name.replace(/\.(b64|base64|pem|txt)$/i, '');
      file.filename.value = base === name ? name + '.bin' : base;
    }

  function setFile(f) {
    currentFile = f;
    resetFileResult();
    file.info.textContent = `${f.name} (${formatSize(f.size)})`;
    suggestFilename();
  }

  async function runFile() {
    resetFileResult();
    if (!currentFile) {
      setMsg(file.error, 'Choose a file first.');
      return;
    }
    try {
      if (fileMode() === 'encode') {
        const bytes = new Uint8Array(await currentFile.arrayBuffer());
        const pem = file.pem.checked;
        let out = B64.encodeBytes(bytes, { mimeSplit: file.mime.checked && !pem });
        if (pem) out = B64.wrapPem(out, file.pemLabel.value.trim() || 'CERTIFICATE');
        fileResult = { data: out, type: 'text/plain' };
        const note = `${formatSize(bytes.length)} → ${formatSize(out.length)} of Base64`;
        if (out.length > MAX_DISPLAY) {
          setMsg(file.notes, `${note} · too large to display, use Download or Copy`);
        } else {
          file.output.value = out;
          setMsg(file.notes, note);
        }
      } else {
        const text = await currentFile.text();
        const pem = B64.detectPem(text);
        const bytes = B64.decodeToBytes(text);
        fileResult = { data: bytes, type: 'application/octet-stream' };
        const dump = B64.hexDump(bytes);
        file.output.value = dump.text;
        const notes = [];
        if (pem) notes.push(`PEM: ${pem.label} detected, armor stripped`);
        notes.push(`${formatSize(bytes.length)} decoded`);
        if (dump.truncated) notes.push('preview shows the first 64 KB');

      }
    } catch (e) {
      setMsg(file.error, e.message);
```

````markdown
# Base64 Tool

An offline, single-file Base64 encoder/decoder modelled on base64decode.org.
Open `dist/base64-tool.html` by double-clicking it. Nothing you paste or drop is sent anywhere:
the page has no external resources, and its Content-Security-Policy (`default-src 'none'`)
blocks all network requests.

## Features

- **Decode:** Base64 → text in any common charset (UTF-8, UTF-16LE/BE, Windows-125x, ISO-8859-x, Shift_JIS, GBK, …).
  - Lenient: accepts whitespace, missing padding, and both the standard and URL-safe alphabets.
  - Errors show the exact character and its position.
  - PEM armor (`-----BEGIN …-----`) is detected and stripped automatically.
  - Binary output is shown as a hex dump and can be downloaded as raw bytes.
- **Encode:** text → Base64 as UTF-8, UTF-16LE/BE or ISO-8859-1, with options for URL-safe, 76-char MIME lines and PEM wrapping.
- **Both modes:** live mode, and *Each line separately*.
- **File:** encode any file to Base64/PEM, or decode a Base64/PEM file back to its original bytes.

Tip: PowerShell `-EncodedCommand` payloads are UTF-16LE. Pick that charset when decoding them.

Requires Node 18+ (developed on Node 24). No npm install; there are no dependencies.
````
